# Screenshot checklist

Use this after the assessment is finished, when you want images for the README, LinkedIn, or a portfolio PDF.

The images should show your work. They should not show the scaffold before you have filled it in.

## Rules

- Keep the fictional notice visible in at least the first image.
- Delete every `EXAMPLE ONLY` row before you capture a sheet.
- Do not include a real employer, a real mine, a real person, an identity number, a password, or a live network address.
- Use a clean desktop. Close unrelated tabs and mail.
- Capture enough of the screen that a reviewer can read the column headings and a few of your rows.
- Prefer PNG files. Name them as below and keep them in `docs/screenshots/`. Create that folder when you take the first image.
- A shot of a blank template does not count. Your ratings, tiers, scores, and roadmap cells must be visible.

## Optional extras

- A second ISO image that shows one `Not applicable` row with the reason written in the evidence cell
- A NIST image that shows Govern next to a Red Dune outcome, so IT and OT are both visible
- A short screen recording, under two minutes, where you open the profile diagram, then the risk register, then the roadmap, and say which risk drove the first 30 days

If you record the screen, use the same rules. Say out loud that the company is fictional.

## Before you post the images

1. Search the sheets for `EXAMPLE ONLY` and remove any hit.
2. Check that a high score in the risk image appears in the roadmap image.
3. Check that the diagram image is the rendered picture, not the mermaid source with broken layout.
4. Read the file names in a folder listing. A reviewer should know what each image is without opening it.
5. Put a one line caption under each image if you embed it in the README. State what judgement the image is there to prove.

## What this checklist replaces

Do not use a generic application screenshot list. This project is a set of documents and spreadsheets. The images above are the ones that show governance, risk, and compliance work.
